## 已修复

1. **播放前校验不一致**：原先仅 `record_only` 校验轨迹数组和目标限位；`stop_on_fault` 的直接调用可能将越界目标送入渐进限速器。现在两种策略均在打开音频和串口前检查非空轨迹、维度、有限数、位置范围、帧率和重复 ID，并补充回归测试。
2. **干净检出无法测试**：测试原来读取本机歌曲输出和完整录制 CSV。改用三帧合成数据与仅含表头的 61 通道文件；旧标定移入测试样例，可选模型绑定测试在无模型时明确跳过。现有录音与生成文件未修改。
3. **外部依赖未固定恢复方式**：播放器依赖被忽略的 FTServo_Python。增加固定提交清单与恢复工具；最小 Python 依赖补齐 NumPy、SciPy、jsonschema。
4. **模型版本可能静默漂移**：下载工具原来每次取远程最新版本并覆盖清单。现在默认复用已保存快照，仅显式 `--refresh` 更新。TensorRT 安装改用六个包的版本与 SHA256 清单，免除对本机大型软件包索引的依赖。
