## 2. 更新方式

直接修改对应条目的固定路径，更新版本、日期及文末变更记录；同步更新本索引的版本号。避免在多个文档中分别维护同一份完整人设。

当前小帅已通过`configs/knowledge/xiaoshuai.json`接入云端实时语音及备用文本聊天：角色文档第1～4节、配置选中的业务事实，以及本机已授权的职业背景摘要。更新后重启P1生效；实际可执行能力仍来自节目目录，未来愿景不冒充当前功能。
