## 42. 短暂循声回应验收（2026-11-26）

目标：已有主聊天人时，侧方有人插一句，机器人朝该侧短暂示意并说“稍等。”，约2秒转回主人。保留原聊天身份和会话，不把旁人的话登记成主人的留言或偏好。大角度只做预算内的示意；现场先校准安装方向。[实现和取舍说明](HK_QXMIC_V3_INTEGRATION.md#14-聊天中的短暂循声回应2026-11-26)。

1. **先核对方位。** 保持P1停止，运行`./tools/check_sound_direction.sh --seconds 30`。在机器人正前、左、右分别说一句话，记下编号。目前只是暂按08为前、编号增大为机器人右侧，尚未经实测；不同就先反馈或修改[配置](../../configs/perception/sound_direction.json)的`attention.mount`，不要靠调整舵机参数纠正方向。
2. **单人基线。** 操作者启动`sudo systemctl start vivis-p1.service`，等待自检和回中通过。A面对镜头，完成几轮普通聊天，确认原身份、默认微笑、口型和跟随正常。让机器人答完，A停留片刻，勿一直移动。
3. **旁人短句。** A仍在画面内，B在相差至少两个方位格（约60°）的侧方说“你好”。应听见短句“稍等。”，看到眼颈向B所在侧示意，随后回到A；业务逻辑身份仍为A。左右各测3次，两次间隔至少5秒。记录从B开口到开始转向、首声和返回的时间。
4. **不串记录。** B在相同侧方说“记住我喜欢咖啡”或“把何工的留言给我”，随后A问自己的偏好、留言状态。B的插话不能记到A名下或以A权限执行。日志应出现独立的循声记录；主会话未被换名。短句已在本地屏蔽时，云端没有完整ASR属于预期，不要求为它伪造一条识别文字。
5. **主人离开。** 重复第3步，在短暂示意期间让A离开。转回后应继续向刚才B的方向尝试找脸；B出现在可达视野内时，按正常视觉规则认识B，不能沿用A。找不到、声源在身后超出范围时应收住并回中，不无限来回找人。
6. **不误触发。** 测机器人自播、旁边无意义噪声、A自己说话，以及声源串口临时没有数据。不能不停左右摆头。主人的有效对话、正在办理的业务和原三种唤醒方式仍可用。音箱播放与真人重叠且无法可靠分离的片段，首版可能不转头，不能拿放松回声保护换触发率。
7. **取消和恢复。** 在接续聊天中要求待机或点歌，确认既有停止、交接、回中和任务流程正常；过期循声请求不能在新节目里突然转头。重连后不重放旧插话。若方向不符或效果不合适，可关闭`attention.enabled`后重新启动。

日志在当前会话`voice/cloud_events.jsonl`，关注`sound_attention_begin`、`sound_attention_returned`、`sound_attention_finished`及可选的`side_speech_isolated`。其中返回时间是目标轨迹记录，实际到位以观察和已有编码器反馈核对。正式验收分别记录触发成功率、误触发、往返时间及主身份是否保持，不把一次最快结果当成整体验收。


### 42.1 检查实际方位链路，再做插话（首轮故障修正）

本次补装语音环境串口依赖后，旧进程已能打开串口；新状态日志及能力上下文需要重启服务加载。测试结束后执行`sudo systemctl restart vivis-p1.service`，不要一边运行独立串口读取器一边测试接待，两者会争用同一CH340。

1. 查看日志出现“声源串口已打开”；若显示`No module named serial`等错误，先处理实际语音环境依赖，不能把“实时语音已就绪”当作声源链路也正常。
2. 在前、左、右分别说一句，查看“声源方位：收到坐标XX”。只看到ASR文字还不代表接收到了方向数据。校对安装方向后，才继续测转向。
3. A单人留在画面里，B在侧方插话。若不转向，记录同一时刻的“循声未触发”原因和本会话`voice/sound_direction.json`，区别数据过期、视线未稳、角度不足、回采重叠或主流程忙碌。陌生的主聊天人不需要先成为熟人。
4. 问“你能转头吗”“为什么没转向”“我在哪一边”。应查询真实状态，区分结构能力、自动功能、当前链路与执行结果；未知位置不能猜成正前方。

根因及修复范围见[声源专项第15节](HK_QXMIC_V3_INTEGRATION.md#15-首次聊天循声未触发实际语音环境缺依赖2026-11-26-2034)。

## 43. 侧方语义响应与熟人在线引介（2026-11-26夜间）

本轮离线开发，机器头断电。次日上电并完成正常启动自检、回中，再重启服务加载新代码。打开日志：

```bash
sudo systemctl restart vivis-p1.service
journalctl -u vivis-p1.service --since '1 minute ago' -f
```

先确认“声源串口已打开”“声源方位：收到坐标XX”。前、左、右的真实对应仍需现场校对；不能把LED方向变化或离线检查通过当作自动转向已经通过。

| 顺序 | 人工操作 | 应看到／听到 |
| --- | --- | --- |
| 1．普通插话 | A单人在镜头前聊天；B在约60°以上侧方、不要入镜，等音箱停下后问“小帅，今天星期几？”；左右各试。 | 小幅侧看并返回A，简短回答原问题；主业务身份仍是A。控制台另标侧方发言人，原话不应被记到A名下。记录实际听完、头返回及音箱首声时间。 |
| 2．连续追问 | B紧接着问一个不同问题；A随后主动继续说话。 | 五秒内可不再转头，但不能因此丢掉B的新问题；A开口后，已过时的侧方回答让开。 |
| 3．在线介绍 | 使用一位尚未登记的新访客A。何工或小王站在侧方，说“这是杨明扬教授，人民大学信息学院的老师，研究灵巧手，欢迎杨教授参观。” | 日志本轮介绍人声纹为确认才可授权；机器人用“杨教授”欢迎并自然接话，不把主身份切成介绍人。长介绍可以讲完，头先回到A方向。姓名示例只用于新测试人物，不能把已有熟人重复登记成杨教授。 |
| 4．看后台结果 | A保持单人正脸并继续聊天，在审核页点击“刷新清单”。 | 控制台出现建档完成；无需重启相机，新人物经过原有连续确认后出现在图像结果中。审核页／人物文件中有初始锁定照片，后续逐渐补样。第一句的欢迎不等于人脸已识别成功。 |
| 5．称呼与补充 | 换另一位新人，只介绍“这位是张老师”；再用另一位新人只说“这是我们的软件工程师”，等询问后由同一熟人完整补充称呼。 | 只有称呼也能建档；缺姓名和称呼则先问。缺资料时不猜姓名、不把“软件工程师”当姓名；介绍人本轮声纹未确认时如实要求完整重说。 |
| 6．防串档 | 介绍进行中让A离开、另一人占据同一位置，或两人同时入镜；随后恢复单人。 | 不能拿新来人的照片登记到A；不满足绑定时等待或报未完成，重新介绍后再办理。 |
| 7．权限和来源 | 未确认的B要求读取A的留言；已确认的B要求查询自己的留言；快递员按明确姓名／尾号取授权码。 | 前者拒绝，后两者按原账本规则处理。介绍人的录音可归其自己的插话记录，绝不能进入新访客声纹库；既有other历史不合并进新人物。 |
| 8．复访 | 记录新人的档案ID，稍后离镜再回来；最后可在正常停机后重新启动复访。 | 热更新和重启后资料均存在；图声结果如实显示。照片总数≤32、活动≤16、声音≤32；声纹仍需本人合格样本达到原活动参考条件，不承诺首次介绍后立刻靠声音认出。 |

每项记录具体时刻、主聊天人、侧方发言人、实际方位、原话和结果。约两秒是往返体验目标；云端回答的实测延迟需单独记录。若朝向错，优先校准安装映射，别通过修改舵机限位／方向掩盖问题。

## 44. 侧方转向与无脸寻人复测（2026-11-27）

现场前提：正常启动自检、回中通过；保留当前限位、速度及反馈保护。第43节的语义响应和引介继续适用，往返时间按本节约六秒替代原两秒。只做正常交互验收，不注入虚假声音或绕过保护驱动舵机。

| 顺序 | 操作 | 预期 |
| --- | --- | --- |
| 1．左右 | 小王面对镜头正常聊天；何工分别在机器人的左、右侧插话。等上次动作结束至少五秒再测下一边。 | 眼颈朝实际发声侧转动。按机器人自己的左右记录，不混用观察者左右；若仍反向记录时刻、方位和串口坐标。 |
| 2．停留与返回 | 两人保持位置，何工说一个简短问题。 | 可看到转过去、停留约1.5秒、再回来，目标往返约5—6秒。回应原问题，主聊天人仍为小王，不能因旁边何工的声纹结果切成何工。真实音频延迟单独记录。 |
| 3．无脸入口 | 先正常进入交互，再离开镜头、站在颈部可达的侧方说话。若已经待机，先明确喊“小帅”。 | 无需先有主聊天人，日志出现“无脸循声找人”，向声源寻找。普通原话仍进入对话，不因动作被吞掉；原有业务核验继续适用。 |
| 4．找到人脸 | 朝侧方说话并保持在转动后能看见的位置。 | 停稳后找到脸，出现“循声找到人脸，已交还视觉跟随”，继续正常眼颈跟随；是否认出姓名看真实图声结果。 |
| 5．找不到人脸 | 交互时从可达侧方说话，但保持背对或不入镜。 | 寻找和观察后回中，日志显示未找到；不无限转动，不越限搜索。 |
| 6．误触发和切换 | 安静、机器人自播、待机中未喊名字、寻人时要求休息；随后再正常唤醒。 | 安静／自播不触发；待机仍遵守原三条规则；模式切换不继续旧寻人，无旧目标突然冒出。 |

记录用户开口、首个转向、停留、返回和实际出声时刻。软件回放验证目标限位与平滑交接，实际方向、硅胶动作和时间由现场确认；大角度受既有保护约束，不以强制达成六秒为由放宽保护。
