# 常见问题

版本0.2｜2026-10-26。

| 现象 | 检查与处理 |
|---|---|
| 缺少音频/目标文件、SHA256不符 | 运行`python -m vivis.runtime.assets`核对，核对Git工作区并恢复对应受跟踪资源；不修改哈希绕过校验 |
| 串口权限拒绝 | 检查USB重插后权限及`tools/99-vivis-servo-access.rules`；按错误提示为当前用户授权 |
| dms/ies占用 | 正常停止相应服务后重试，不同时启动其他舵机或相机控制程序 |
| 8765已有不同配置服务 | 查看旧视觉服务的启动终端并正常退出，然后重开示例；不得把未核验相机服务直接复用 |
| 打不开相机 | 检查实际by-id节点；使用`--camera-device`。两眼相机的节点和方向须分别确认，节点编号可能随USB插拔改变 |
| 能框出人脸但真机不动 | 确认运行的是示例2/3，检查控制状态与日志；预览绿框本身只说明检测，不证明串口控制正常 |
| 示例1没有预览 | 正常，面部模式不启动相机；眼球和颈部仅在开头回中 |
| 有声音但口型不同步 | 核对WAV和表情是否同一作品、音频设备与延迟；控制跟随DAC时间轴，不重新生成另一份音频 |
| 电机型号或限位不符 | 对照硬件配置和实际本体，保存读回再检查；不自动改限位适配陌生设备 |
| 坏包或反馈看门狗停止 | 保存`summary.json`、`preparation.json`、播放日志和串口轨迹；核对接头、供电、总线速率与占用，不反复放宽保护 |
| 重启后参数变化 | 启动阶段会按硬件配置恢复并读回；检查是否存在其他程序覆盖或设备型号变化 |
| 切换500kbps后无法启动 | `--baud`只设主机，先确认全部35轴已完成同速配置及重启核验；当前默认仍1Mbps |
| Ctrl+C后暂时保持动作 | 停止发送不等于切断扭矩，舵机可完成最后目标；本程序保留颈部支撑扭矩 |

新入口测试的日志位于`outputs/developer/`。一份日志只证明对应模式和作品的结果，不能将静态核验、离线通过或中途退出算作整曲完成。
