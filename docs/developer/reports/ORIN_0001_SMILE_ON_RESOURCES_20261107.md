## 1. 结论与覆盖范围

小帅真机完整播放作品1《白骨夫人》一遍，音频112.893秒。Orin本地实时A2F生成6774帧，未读取旧表情JSON；A2F供帧断流计数为0，程序正常结束。正式播放阶段整机CPU平均18.61%、采样峰值25.11%；GPU平均11.08%、采样峰值98.00%；系统已用内存平均6.38 GiB，交换分区使用0。

本轮平均CPU和内存仍有余量，未观察到A2F供帧不足。GPU存在短时高负载，不能据均值估算可并发节目数，也不能据本轮推断长时间稳定性或真机口型精度。

`--smile on`已开启Face Landmarker微笑识别。整段视觉服务处理1680帧，其中1661帧检测到人脸，1177帧得到有效微笑检测结果；**本轮微笑回应触发数为0**。因此本报告覆盖开启微笑识别的运行成本，未覆盖实际微笑回应触发后的负载或表现。眼球与独立三轴颈部跟随均开启。没有运行语音节目管理器、ASR、TTS、LLM或模型训练。

## 3. 测量方法与阶段结果

使用`tegrastats --interval 1000`采样GPU、系统RAM、交换分区和温度；同时每秒读取`/proc/stat`、`/proc/meminfo`及任务进程树的CPU计数、`smaps_rollup`内存。进程树覆盖控制程序、原生A2F与视觉服务；后台系统进程只计入整机指标。

开始前采集约10秒空闲基线，应用退出后继续约10秒，共152条采样记录。正式播放边界由保留的音频时间戳与单调时钟对应关系估计，时钟偏移范围2.19毫秒；统计剔除跨阶段的1秒CPU计数区间。GPU读数取距采样时刻不超过1.5秒的有效值，**所列峰值均为采样最大值，不能代表捕获了全部瞬态尖峰**。

CPU百分比统一以12核总容量为100%。进程CPU另以“核”表示，1核=一个CPU核心满负荷；原始进程百分比可超过100%。系统RAM使用tegrastats口径；任务内存采用进程PSS之和，避免直接相加RSS重复统计共享页。PSS只归属CPU可映射内存，不等于全部GPU分配。Orin是共享内存架构，`nvidia-smi`未提供独立显存容量，不能将任务PSS和系统RAM相加，也不能把二者差值当作GPU显存。

## 4. 同步与运行质量

- 应用返回码0；播放完成标志为真；实际音频时钟结束于112.896811秒，完整音频目标112.893375秒。
- 实时生成6774帧，非法权重0；A2F供帧断流0次。没有以旧表情JSON代替实时推理。
- 摄像头实际处理频率约12.94Hz，单帧处理耗时中位数29.67毫秒；主机观测帧龄P95为210.58毫秒。相机请求30fps、检测目标20Hz不等于这些实测值；帧龄也不是人脸运动到皮肤动作的端到端延迟。
- 控制日志累计6774次控制迭代；`skipped_source_frames=344`记录名义时间格点跨越，实时源按音频时间插值取样，不能把此计数直接当作A2F丢帧率。精简日志只保留最后600条控制事件，未据此宣称全程每帧均严格满足16.67毫秒。
- 总线累计43760次读取请求，234次失败（0.535%）；统计覆盖同一总线会话中的准备与播放，不等于播放阶段独立错误率。本轮未触发停播保护；仍不能将已有坏包归因于CPU/GPU，也没有证明通信完全无误。
- 本轮未触发微笑回应，不能据此报告微笑动作效果；此次没有改变微笑阈值来制造触发。

```bash
  --robot configs/robots/xiaoshuai/robot.json \
  --work 0001 --repeat 1 --smile on \
  --compact-logs --overlap-warmup
```

带资源记录的复测（显式执行真机动作，目录需为新目录）：

```bash
BENCH="outputs/resource_bench/$(date +%Y%m%d_%H%M%S)_smile_on"
.venv/bin/python tools/profile_runtime_resources.py \
  --output "$BENCH/capture" --baseline 10 --tail 10 --timeout 240 -- \
  .venv/bin/python -m vivis.interaction.programs singing \
  --robot configs/robots/xiaoshuai/robot.json \
  --work 0001 --repeat 1 --smile on \
  --compact-logs --overlap-warmup --output "$BENCH/performance"
```

原始采样为`capture/samples.jsonl`，GPU/RAM原始日志为`capture/tegrastats.log`，阶段事件为`capture/events.jsonl`，程序输出为`capture/application.log`；运行结果位于`performance/`。`analysis/resources.csv`是全部采样，`analysis/processes.csv`为逐进程记录，`analysis/summary.json`含分阶段指标和口径。处理脚本`analyze.py`用系统Python与matplotlib离线生成CSV、图和本报告，不参与真机控制。

本报告仅为该软件基线、该功耗模式、该作品及一次现场场景下的测量。未做并发容量、长时间热稳定性、微笑触发效果和ASR/TTS/LLM全链路压力测试；没有把Orin资源余量直接等同于皮肤口型表现。
