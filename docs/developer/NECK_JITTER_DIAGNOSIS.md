## 2. 优先排查的原因

1. **舵机位置环与机构的静态振荡。** 若停止发送、保持固定目标后仍抖，优先查PID、零死区、结构刚度、齿隙、偏载与牵引方向。此前扶住后抖动减弱、左右不对称，是线索，尚不是机械故障结论。
2. **小步进目标配高执行速度。** 64限制的是目标轨迹加减速；硬件加速度0、速度1000仍可能让每个小目标迅速执行后停住。成功轮ID32目标有220次变化，典型步长2计数、变化间隔中位数约66毫秒，最大步长3计数。软件轨迹平滑不等于轴输出连续平滑，此项须用固定轨迹与编码器验证。
3. **视觉误差和眼颈闭环噪声。** 眼内相机随眼球运动，检测抖动、眼球反馈方向变化和控制反向可能导致目标反复修正。若固定目标/轨迹平顺，仅人脸跟踪抖动，再查该链路。
4. **反馈时序、供电与固件。** 比较指令时间、编码器、电压、负载和报警；成功短片无坏包不能排除其他时段的电源或总线问题。现有采样电压不能排除短时尖峰。

代码审查还发现：自适应速度调度器的计算值此前只进入诊断，发送层没有采用。本轮已接通并增加边界检查和离线测试；默认`adaptive_speed=false`，因此当前实际速度仍1000，尚未开启新策略，也不能把该修复当作抖动已解决。

## 3. 明天的现场步骤

一次只改变一个因素，先保存每轮实际参数和日志。沿用当前跟踪范围，不做全行程扫描。

1. **上电只读基线。** 读取ID32及31/33/34对照：固件、模式、相位、PID、死区、硬件加速度及倍数、速度、最大/运行扭矩、过载阈值/时间/保持扭矩、当前位置/目标、状态和电压。确认启动后实际值与保存配置一致。
2. **固定目标保持。** 低速回中后关闭跟踪目标更新，观察中位保持及左右小偏移保持。分别记录是否抖、频率、方向、负载和位置误差；静态也抖时，不先调视觉滤波。
3. **固定轨迹对照。** 使用小范围、相同往返轨迹，左右分别观察，记录时间戳目标、实际发送速度与编码器。先保留PID/死区，只比较固定1000与调度器的适配速度，避免同时改PID和速度。
4. **再区分位置环问题。** 若保持也抖，先单独试小死区（如1/1），再根据结果单独调整P或D。每次恢复已记录基线再做下一项；不能保证增加D或降低P对两侧都有效。
5. **最后恢复眼颈跟踪与完整播放。** 先只有跟踪，再加入表情和音频；比较目标反向次数、时间间隔、位置误差和现场平顺程度。

合格应同时满足：现场左右转与保持平顺、目标无无效往返、跟踪可用、反馈和设备状态正常。只有`completed=true`只说明流程结束；不能代替该项运动品质验收。
