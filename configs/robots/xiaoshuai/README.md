# 小帅（xiaoshuai）：配置与作品1

小帅：男性，28岁。舵机分布同小白，设备清单为ID2～34共33轴：2～30读数521，31～34由用户确认是SM45BL，读数11272。配置和标定保存在本目录，控制代码与墨甲共用。

## 1. 首轮播放：面部＋完整音频

在项目根目录执行：

```bash
./examples/01_face_control/run.sh \
  --robot configs/robots/xiaoshuai/robot.json \
  --work 0001 --repeat 1 \
  --mouth-command-mode lips-direct --mouth-speed 600
```

末尾加`--check`仅做离线检查。首轮口部硬件速度上限600计数/秒，表情/圆唇增益均为1.0；每遍先以不超过60计数/秒缓慢准备25个面部轴，再从头播放完整作品1。显示`ROUND 1/1 COMPLETE`为本遍正常完成。

本轮不打开相机。眼球7/8/22/23、未映射29和颈部32/33/34不参与回中、位置发送或使能；ID33未使能的被动位置偏差不会触发本轮颈部恢复。两个跟踪示例当前会在访问设备前拒绝小帅模式，待安装和方向核验后再接入。停止沿用最后合法目标，不突然卸载受力机构；小帅不执行墨甲专属ID29吐舌恢复或结束卸载。

## 2. 文件及唯一配置来源

| 文件 | 用途 |
|---|---|
| `robot.json` | 身份、支持模式、其他配置引用及相机设备入口。 |
| `calibration.json` | 原始`小帅无色测试版6.22（16.24）.json`逐字节副本，52个表情端点。 |
| `hardware.json` | 33轴清单、各轴型号、中位基准、实际回中例外、当前设备限位、速度与加速度。 |
| `homing.json` | 本轮25轴准备清单、60计数/秒回中及未使能轴的小幅偏移复核。 |
| `tracking.json` | 当前只记录相机及未启用的跟踪状态，不复制墨甲并联平台几何。 |
| `telemetry.json` | 软件告警与连续传感器故障确认策略，舵机自身保护保留。 |
| `works.json` | 小帅的作品清单，引用共享媒体与小帅专属轨迹。 |
| `calibration_comparison.json` | 标定差异、只读设备快照及用户确认依据；不作为运行硬件配置加载。 |

作品1原音频和61通道源数据与墨甲共享，仍位于`assets/works/0001/`；小帅电机目标独立保存为`assets/works/xiaoshuai/0001/targets.json`。选择`--robot`后会读取对应机器人的作品清单，不覆盖墨甲的轨迹或配置。

## 3. 中位、限位与首轮处理

用户已确认表情零权重位置统一2047，ID31同样采用2047。ID24为颧骨轴，用户允许选择合理的可达回中位置：其设备上限2030，因此`hardware.json`保留`neutral=2047`作为换算基准，单独设置`home_position=2030`。

运行时区分两种含义：映射仍按2047计算位移，回中和命令范围检查使用可达目标2030。不会通过把零权重基准改成2030来改变表情换算公式。ID24在本标定中的唯一端点为2030，当前范围裁剪后作品1全程为2030，首轮不承担动态颧骨表现。

用户已选择按当前EEPROM限位裁剪。限位来自只读地址9～10（下限）、11～12（上限），两字节小端；它们是固件配置行程，不等同于机械挡块。源标定及设备限位没有改写。

标定31个端点超限、涉及18轴的完整清单见比较报告。实际作品1共有6774帧：ID5裁剪172帧、ID20裁剪143帧、ID21裁剪178帧、ID24裁剪6774帧，其余轴没有位置裁剪。裁剪不补造眨眼或静音闭嘴事件。

ID24曾读到未使能位置2045，比上限高15计数；仅在未使能、两次位置复读一致且偏差不超过20计数时允许按既有缓慢启动流程进入范围。所有发送目标仍位于1600～2030内，临时反馈通道仅用于准备阶段；实际目标和播放反馈限制不扩大。

首次启动只设置/核验本轮速度与已保存加速度，并沿用现有受限位置/使能流程；小帅配置未请求PID、死区、设备限位或相位改写。当前加速度原值为0，600为首次测试的速度上限，不宣称已经完成动态性能整定。
